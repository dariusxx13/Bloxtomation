# Economy sheet template

Build this in any spreadsheet (or as a CSV generated by a script). The game template in this repository includes a Lune script that produces the same table from config so the sheet and the game never drift.

## Inputs (one block per player type)

| Input | Casual free | Typical | Paying |
|---|---|---|---|
| Actions per minute (core loop) | 30 | 45 | 50 |
| Session length (minutes) | 10 | 20 | 30 |
| Sessions per day | 1 | 2 | 3 |
| Active multipliers (passes, pets) | 1.0 | 1.5 | 3.0 |
| Efficiency vs optimal play | 60% | 80% | 90% |

## Levels table (one row per upgrade level or goal)

| Column | Formula or source |
|---|---|
| `id` | Goal id (`upgrade_power_7`, `zone_3_gate`, `rebirth_1`) |
| `type` | upgrade / gate / rebirth / unlock |
| `cost` | `C0 * r^L` or config value |
| `income_per_min` | `base_income(L) * multipliers * efficiency` |
| `minutes_to_afford` | `cost / income_per_min` |
| `cumulative_minutes` | running sum |
| `session_index` | `ceil(cumulative_minutes / session_length)` |
| `day_index` | `ceil(session_index / sessions_per_day)` |
| `target_minutes` | from design (for example first goal 10-15 min) |
| `delta_vs_target` | `cumulative_minutes - target_minutes` |
| `notes` | what unlocks; system introduced |

## Checks the sheet must show

- First upgrade under 1 minute for every player type.
- First named goal at 10-15 minutes for the casual free player.
- No gap above about 3 minutes in the first hour for the typical player.
- First rebirth between 30 and 60 minutes for the typical player.
- Paying player reaches goals faster but not absurdly (for example within 2-4x, not 50x).
- Maximum multiplier for a maxed paying player computed and capped.

## Drop table tab

| Column | Content |
|---|---|
| `egg_id`, `item_id`, `tier` | identifiers |
| `weight` | config weight |
| `probability` | `weight / sum(weights)` |
| `one_in` | `1 / probability` |
| `rolls_for_50pct` | `0.69 / probability` |
| `minutes_to_50pct` | `rolls_for_50pct * seconds_per_roll / 60` (per player type) |
| `with_luck_Lx` | probability with luck applied using the game's real formula |

## Revenue tab (estimates)

| Input | Value |
|---|---|
| DAU | |
| Payer conversion | |
| ARPPU (Robux) | |
| Creator share | 0.70 |
| DevEx rate | 0.0038 (check current) |
| Output: Robux earned per day | `DAU * PCR * ARPPU * 0.70` |
| Output: USD per day | `Robux earned * DevEx rate` |
