# Pitch template

Copy this into a new file named `pitch-<short-name>.md`. Fill every field; write "unknown" rather than guessing. See [Pitch and greenlight](../15-market-research/pitch-and-greenlight.md) for the scoring rubric.

```markdown
---
title: Pitch: <working title>
date: <YYYY-MM-DD>
status: draft | submitted | approved | parked | declined
author: <human or agent role>
---

# <Working title>

## One-liner
You <verb> to get <reward> so you can <goal>.

## Genre and audience
- Roblox genre / subgenre: <genre> / <subgenre> (why: <chart visibility reasoning>)
- Target tier: Kids / Select / 16+ ; expected maturity label: <Minimal/Mild/Moderate>
- Devices: phone-first / PC-first ; tourists vs locals appeal: <notes>

## The game
- How it plays (core loop): <2-3 sentences>
- First 60 seconds: <player actions>
- Goal at 10-15 minutes: <named goal as a player action>
- Minutes 10-30: <what keeps them going>
- Why tomorrow: <return hook>
- Friend reason: <why better with friends>
- Clip moment: <the moment players will record>
- How it makes money: <main products and why they are fair>
- Icon concept: <what the 150 px icon shows>

## Evidence (fresh: no older than 7 days)
| Source | Date (UTC) | Metric | Value | Note |
|---|---|---|---|---|
| Chart snapshot <sort> | | rank / players | | |
| Comparable game <name> | | players, visits/day, like % | | |

- Read: we could be early / we would be late, because <evidence>

## Build estimate

- Launch content: <scope, time>
```
