# Reference games by genre

Before building in a genre, play its best games with a question in mind. This list names the games and the question. Data points come from the studio's chart snapshot (2026-10-24, 17:04 UTC), third-party trackers, award lists and official posts, all dated; they show scale, not quality. **Study, do not copy**: names, art, characters and distinctive designs stay original ([IP and licensing](../17-policy-and-business/ip-and-licensing.md)). How to run a structured teardown: [Competitor teardown](../15-market-research/competitor-teardown.md).

## How to study a reference game (Rule of thumb)

1. Play the first 10 minutes as a new player on a phone; record it ([First session blueprint](../01-first-five-minutes/first-session-blueprint.md)).
2. Write the loop in one sentence and the first goal time.
3. List the shop: products, prices, categories ([Product catalog](../09-monetization/product-catalog.md)).
4. Note the live calendar: update day, events, codes ([Update cadence](../12-live-ops-and-launch/update-cadence.md)).
5. Track it with the chart tracker for a week (`python3 charts/charts.py game "<name>"`).
6. Write what you would do differently: the twist.
