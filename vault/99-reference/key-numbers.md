All values dated **2026-10-24**. "Fact" means documented by Roblox (link in [Sources](sources.md)); "Rule of thumb" means a community or vault heuristic. Re-check facts before financial or launch decisions.

## Design rules of thumb (this vault)

| Item | Value |
|---|---|
| Core action reachable | within 30 s of spawn |
| First reward | within 90 s |
| First upgrade | within 3 min |
| First named goal | 10-15 min for a casual free player |
| First rebirth | 30-60 min |
| Upgrade gaps in first hour | under ~3 min |
| Cost growth per level (early lines) | r = 1.15-1.6; r/g = 1.03-1.15 |
| Hard pity | ~2-3x expected rolls |
| Daily quests | ~10-20 min total |
| Offline earnings | capped 2-12 h; 10-50% of active rate |
| HUD | ≥ two thirds of a small phone screen shows the world |
| Left menu stack | 4-7 buttons |
| Update cadence | weekly ideal, monthly minimum |
| D1 retention | weak <10%, healthy 12-20%, strong 25%+ (varies by genre) |
| Payer conversion | ~1-3% common for casual games (varies widely) |
