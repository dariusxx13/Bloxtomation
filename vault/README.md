# Bloxtomation Vault

A complete, practical knowledge base for making Roblox games that people play, return to and pay for. It covers design, art, engineering, monetization, discovery, live operations, market research, policy and running an AI agent team. It is written for humans and for AI agents.

**New here?** Read [How to use this vault](00-start-here/how-to-use-this-vault.md), then [The Roblox platform in 2026](00-start-here/roblox-platform-2026.md) and [The hit formula](00-start-here/hit-formula.md).
**An AI agent?** Read [For AI agents](00-start-here/for-ai-agents.md) first.

## Conventions

- Facts are dated 2026-10-24. Platform facts link to official sources; rules of thumb are labelled as such.
- Links are relative markdown links, so the vault works in Obsidian, on GitHub and in VS Code. Open this `vault/` folder as an Obsidian vault.
- Every note ends with a `Related:` line; every folder has an `INDEX.md`.

## Using the vault with the rest of the repository

- `template/`: the game template that implements the engineering rules in section 13.
- `agents/`: the AI agent team described in section 16.
- `charts/`: the chart tracker described in section 15.
