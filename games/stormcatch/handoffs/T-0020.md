### Studio steps (for the verification task; run on the human's computer)
Setup, S0:
- Open `games/stormcatch/project/build.rbxl` in Studio. Alternatively, run `rojo serve` and connect the plugin to an empty place with no Baseplate.
- The server builds the world when it starts.
- Run QA commands from the **Client** data model: `game.ReplicatedStorage.Remotes.QACommand:InvokeServer(name, arg)`. Use the Studio MCP `execute_luau` with target Client, or the Settings panel's QA buttons.
- Without "Studio Access to API Services", every Play session starts a fresh in-memory profile. That suits the fresh-profile runs; S3's rejoin needs persistence.
- Server log lines to read: `[Onboarding] ...`, `[StormPull] ...`, `[QA] ...`.

- **S1 (criterion 1, PROTO-01):**
  1. Play solo with Settings > Sound effects ON. Land 8 fish at the Dock Ripple.
  2. Run `forceWeather "cove_shallows showers 120"`, walk to Cove Shallows and land 6. Then run `forceWeather "cove_shallows fog 120"` and land 6 (Sea Fog doubles Rare and up).
  3. For every catch, note: a tick on each good tap; a splash with audible pitch variation, alternating two variants; the bobber pop and the fish leap; "+N" flying to the coin counter; the counter bump.
  4. For Rare and Epic catches, also note the particle burst, a cheer (emote or hop), a small shake and a soft flash.
  5. Turn Reduce motion ON for 3 Rare-or-better catches: no shake and no flash.
  6. Turn Sound effects OFF and repeat all 20 catches: layers 2-4 must still show.
  7. Evidence: `exportLog` CSV (tiers), and a clip of one Common and one Rare landing.
- **S2 (criteria 2 and 4, PROTO-03 input):**
  1. Start a fresh Play session in Device Simulator on a phone profile (for example iPhone 13, 844x390, landscape). The tester follows only the on-screen hints.
  2. Time from spawn until the Cast button reads "Cast" and is enabled: it must be 10 s or less.
  3. Land fish, open the pulsing Shop and buy the Rod.
  4. Run `twistStats` and read `players[1].firstCatch` (30 or less) and `players[1].step6` (60 or less).
- **S3 (criterion 3):**
  1. On a fresh profile, play: cast (step 2), catch (3), catch again (4), open the Shop (5), buy the Rod (6).
  2. Run `forceWeather "cove_shallows showers 120"`, walk there and land a fish (7). This must be a Pitterpike with the Drizzled stamp (req. 3.7).
  3. The Output must show `[Onboarding] P1 step 1 Joined` through `step 7 Caught in Rain`, in order.
  4. Rejoin with that profile. This needs persistence: the place saved to Roblox with API access on, or the human's private place.
  5. On rejoin: no hint text, no beam and no button outline at spawn.
- **S4 (criterion 6):**

  3. Check the ring opacity: Sea Fog's ring is faint and its marker solid.

     - Clear: "!" and a splash.
